# Empezá acá ”” Lucian (nuevo sistema)

El sistema anterior (Airtable + Make) queda intacto en `app/`, blueprints y docs.
El **nuevo sistema** está en la carpeta `lucian/` y no depende de Airtable ni de Make.

## Arrancar

1. Entrá a la carpeta `lucian/`.
2. Doble click en `INICIAR-LUCIAN.cmd`.
3. Se abre el navegador. Si es la primera vez, cargá los datos de ejemplo.

Requisito: Node.js 20 o superior. No hace falta `npm install`.

## Guías

- `lucian/LEEME.md` ”” uso completo.
- `DIAGNOSTICO-FLUJO-ACTUAL.md` ”” diagnóstico honesto del flujo anterior.
